# 리피티 (Repeaty) — 헬스 트레이너 고객관리 웹앱

> 고객이 다시 찾는 이유. (Keep them coming back.)

퍼스널 트레이너가 **이동 중에도 1~2분 안에** 일정 확정 · 음성 피드백 · 리포트 발송을 끝내고,
고객에게는 휴먼 터치로 감동을 주어 **다음 달 재등록 전환율**을 높이는 것을 목표로 하는 모바일 우선 웹앱(PWA)입니다.

> 📄 기획 배경과 전략은 [`docs/기획리포트.md`](docs/기획리포트.md) 참고.

## 현재 단계: 프론트엔드 (Phase 1 MVP UI)

백엔드 연동 전, **동작 흐름을 먼저 확인하기 위한 프론트엔드 데모**입니다.
모든 데이터는 `lib/mock.ts`의 목업이며, 화면 인터랙션(녹음·AI 생성·발송 등)은 시뮬레이션입니다.

### 기술 스택 (가볍고 저렴한 풀스택 지향)
- **프론트엔드:** Next.js 14 (App Router) · TypeScript · Tailwind CSS · PWA
- **백엔드(예정):** Next.js API Routes + PostgreSQL(Supabase 무료 티어) · Vercel 무료 배포
- **연동(예정):** Google Calendar(.ics) · 카카오 비즈메시지(발송대행) · LLM(Claude) · STT

### 실행
```bash
npm install
npm run dev   # http://localhost:3000
```

## 화면 구성
| 경로 | 화면 | 설명 |
|---|---|---|
| `/` | 트레이너 홈 | 오늘 일정 · 재등록 대상 · 이탈 위험 · 빠른 작업 |
| `/schedule` | 일정 관리 | 가용 시간 · 예약 링크 공유 · 구글캘린더 연동 |
| `/clients` | 고객 현황 | 현재/이탈위험/예전 세그먼트 · 검색 |
| `/clients/[id]` | 고객 상세 | 성과(비포/애프터) · 리포트 타임라인 · 휴먼터치 |
| `/clients/new` | 고객 등록 | QR · 입력 링크 · 직접 입력 · 명함(OCR) |
| `/reports/new` | 음성 리포트 | 녹음 → STT → AI 리포트 생성 → 발송 |
| `/messages` | 메시지 | 휴먼터치 자동화 트리거 · 예약 발송 · 카카오 |
| `/admin` | 관리자 | AI API Key/모델/프롬프트 · 발송 채널 · 통계 |
| `/book` | (고객용) 예약 | 빈 슬롯 선택 → 확정 → 캘린더 자동 등록 |
| `/intake` | (고객용) 정보 입력 | QR/링크로 진입하는 셀프 등록 폼 |

데스크탑에서도 모바일 폭(460px)으로 중앙 정렬되어 실제 사용 느낌을 확인할 수 있습니다.
