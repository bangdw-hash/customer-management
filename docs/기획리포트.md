# 헬스 트레이너 고객관리 웹앱 — 개발 전 기획 리포트

> 작성일: 2026-06-12
> 대상: 1인(또는 소규모) 퍼스널 트레이너의 고객관리·일정·재등록 전환 도구
> 문서 목적: 개발 착수 전, 웹앱 개발 관점 + 헬스트레이닝 업계의 상업적 관점을 함께 반영한 기획·전략 정리

---

## 0. 한 줄 요약 (Executive Summary)

트레이너가 **이동 중에도 1~2분 안에** 일정 확정, 음성 피드백 작성, 리포트 발송을 끝내고,
고객은 **"내가 관리받고 있다"는 감동(휴먼 터치)** 을 받아 **다음 달 재등록을 자연스럽게 결정**하게 만드는 것이 이 앱의 핵심 가치다.

- **북극성 지표(North Star Metric): 월 재등록(리텐션) 전환율**
- 모든 기능은 "재등록 전환 ↑" 또는 "트레이너 시간 절약 ↑" 둘 중 하나에 기여해야 한다.
- 기능이 많은 것이 목표가 아니라, **이 두 축에 집중**하는 것이 경쟁 앱과의 차별점.

| **온핏 매니저** | 일정·신체정보·세션 피드백 | 트레이너 업무 도구 성격, 고객 감동(휴먼터치) 자동화 약함 |
| **헬린캠프** | 운동일지, 체성분 그래프, 회원 공유, 커뮤니티 | 일정 예약 링크/구글캘린더/AI 리포트 자동화 약함 |

### 1.3 핵심 인사이트 (이 앱이 이겨야 하는 지점)
1. **국내 앱**은 "기록·관리"에 강하지만 **고객 감동 자동화(휴먼터치)** 와 **AI 리포트**가 약하다.
2. **해외 앱**은 기능이 풍부하나 **카카오톡 메시지, QR, 명함, 재등록 문화** 등 한국 시장 핏이 없다.
3. → **우리의 포지셔닝:** "한국형 + AI 리포트 + 휴먼터치 자동화 + 이동 중 1분 처리" 에 집중한 **1인 트레이너 전용 경량 도구**.

> 출처: Trainerize/Mindbody 기능 비교, 포인티·온핏·헬린캠프 소개 (문서 하단 참고자료 참조)

## 2. 상업적 전략 — "재등록 전환율"을 높이는 메커니즘

업계에서 잘 나가는 트레이너의 재등록 비결을 기능으로 번역하면 다음과 같다.

| 상업적 원리 | 앱 기능으로 구현 |
|---|---|
| **진척의 시각화** (고객은 "변화"를 봐야 결제한다) | 세션별 기록 → 비포/애프터, 그래프, 월간 성과 리포트 자동 생성 |
| **휴먼 터치** (관계가 재등록을 만든다) | 생일·기념일·목표달성·연속출석 자동 축하 메시지, "오늘 컨디션 어때요?" 케어 메시지 |
| **잔여 세션 불안 해소 → 자연스러운 재등록 제안** | 잔여 세션 N회 이하 시 트레이너 알림 + 고객에게 맞춤 재등록 제안 카드 |
| **노쇼/이탈 조기 감지** | 출석 패턴 이상(2주 미방문 등) 감지 → "이탈 위험 고객" 대시보드 |
| **마찰 없는 예약** | 예약 링크 한 번으로 예약 완료 → 구글캘린더·카카오 자동 등록 |
| **신뢰의 증거** | 고객별 누적 리포트 타임라인(언제든 다시 열람 가능) |

핵심: **"잔여 세션 + 성과 리포트 + 휴먼터치 메시지"** 세 가지가 만나는 순간이 **재등록 결정의 트리거**다. 이 흐름을 앱이 자동으로 만들어준다.

## 3. 요청 기능 정리 + 구현 방안

### 3.1 일정 관리
**요구사항:** 내 일정 등록 / 고객에겐 예약 가능 구간만 노출 / 공유 예약 링크 / 고객 선택 → 나에게 자동 등록 / 모든 확정 일정 구글캘린더 등록 / 로그인은 구글 아님, 단 일정은 구글캘린더 포맷 기반.

**구현 방안:**
- **로그인:** 자체 인증(이메일/전화 OTP, 카카오/애플 소셜 로그인 선택) — 구글 로그인 불필요.
- **구글캘린더 연동(핵심 요구):** 트레이너가 앱에서 **Google Calendar API를 1회 OAuth 연동**(서비스용 연결). 로그인 방식과 분리됨.
  - 트레이너 일정/확정 예약 → 트레이너 구글캘린더에 이벤트 생성.
  - 고객 일정 → 고객에게 **`.ics`(iCalendar) 파일 / "구글캘린더에 추가" 링크** 제공(고객은 구글 계정 연동 불필요, 한 번 탭으로 자기 캘린더에 추가).
  - 즉, **확정 일정은 모두 구글캘린더(iCalendar/RFC 5545) 포맷 기반**으로 표준화.
- **예약 가능 구간:** 트레이너가 가용 시간 규칙(요일/시간/세션 길이/버퍼)을 설정 → 시스템이 빈 슬롯만 계산해 공개.
- **공유 예약 링크:** 고유 URL(예: `/book/{trainerSlug}`). 고객이 슬롯 선택 → 예약 요청/확정 → 양측 캘린더 동기화 + 카카오 확인 메시지.
- **노쇼 방지:** 예약 24h/2h 전 리마인드(알림톡), 예약 변경/취소 정책.

```
[트레이너 가용규칙] → 빈 슬롯 계산 → [공개 예약링크] → 고객 슬롯 선택
   → 예약 확정 → ① 트레이너 Google Calendar 이벤트 ② 고객용 .ics/캘린더추가 링크 ③ 카카오 확인메시지
```

### 3.2 고객 피드백 관리
**요구사항:** 음성 입력 → 고객용 리포트 생성(AI, API Key는 관리자창에서 입력·관리) / 고객별 저장·날짜별 열람 / 발송 일정 일괄·세부 설정 / 카카오톡 메시지 발송(개인 메시지·사업자 자동 발송).

**구현 방안:**
- **음성 입력:** 브라우저 녹음 → STT(음성→텍스트). → AI가 전문 리포트로 정리(요약/성과/다음 목표/격려 문구).
- **AI 연동 + 키 관리(핵심 요구):** 관리자 화면에 **AI API Key 입력/저장/교체 UI**. 키는 **서버에서 암호화 저장(예: KMS/암호화 컬럼)**, 프론트 노출 금지. 모델·프롬프트 템플릿도 관리자에서 조정 가능.
  - 권장: 리포트 생성에 최신 Claude 모델(예: claude-opus-4-8 / claude-sonnet-4-6) 사용. 키를 사용자가 직접 입력하므로 멀티 프로바이더 추상화 레이어 권장.
- **저장/열람:** 고객별 리포트 타임라인, 날짜 선택 열람, 검색.
- **발송 스케줄:** 즉시 / 예약(일괄: "매주 일요일 20시" 등 / 세부: 고객별 개별 시간).
- **카카오 발송 — ⚠️ 2026 정책 반영 필수:**
  - **친구톡은 2025-12-31 종료**, 2026-01-01부터 **브랜드 메시지(자유형)** 로 대체.
  - **알림톡** 발송 기준도 2026-01-01 개편(정보성 메시지 중심 강화, 광고·유도성 제한).
  - → **정보성/거래성(예약 확인·리마인드·리포트 도착 안내)** 은 **알림톡(승인 템플릿)** 으로, **마케팅성(재등록 제안 등)** 은 **브랜드 메시지/채널 친구 대상** 으로 분리 설계.
  - 발송은 **공식 발송대행(SOLAPI, 비즈고, 다이렉트센드 등) API** 연동이 현실적. 사업자 채널·템플릿 사전 승인 필요.
  - **대안 채널 동시 지원 권장:** SMS/LMS, 이메일, 인앱 알림 — 카카오 정책·승인 리스크 분산.

### 3.3 고객 일반 관리
**요구사항:** QR로 등록 / 연락처 직접 입력 / 고객 입력용 링크 / 명함 등록 / 고객 현황(현재·과거).

**구현 방안:**
- **QR 등록:** 트레이너 고유 QR(예: Bitly QR 또는 자체 생성) → 고객이 스캔 → 셀프 등록 폼.
- **고객 셀프 입력 링크:** 동의 항목 포함한 정보 입력 폼(이름·연락처·목표·건강특이사항·생일/기념일).
- **명함 등록:** 사진 업로드 → OCR로 연락처 자동 추출(선택 기능).
- **고객 현황 대시보드:** 현재 관리 / 과거(휴면·종료) / 이탈위험 / 잔여세션 임박 으로 세그먼트.

### 3.4 휴먼 터치 (자동 알림)
- 생일·기념일·목표 달성·연속 출석·재등록일 D-day 등 트리거 → 자동/반자동 축하·케어 메시지.
- **트레이너 검수 모드** 권장: 자동 초안 생성 → 트레이너가 한 번 확인/수정 후 발송(기계적 느낌 방지 = 진짜 휴먼터치).

### 3.5 관리자 창
- AI API Key·모델·프롬프트 관리
- 카카오/SMS/이메일 발송 채널·템플릿·발송대행 키 관리
- 예약 규칙·영업시간·세션 상품(횟수권) 관리
- 고객·리포트·발송 로그, 통계 대시보드(재등록률·노쇼율·발송 성공률)
- 권한/감사 로그, 데이터 백업·내보내기

## 4. 추가 제안 기능 (목적: 재등록 전환 ↑ & 고객 감동 ↑)

1. **재등록 전환 위젯:** 잔여세션 임박 + 최근 성과 리포트 + 맞춤 제안가를 묶은 "재등록 제안 카드" 자동 생성.
2. **성과 비교(비포/애프터) 카드:** 체중·체성분·기록·사진 변화 → 공유용 이미지 자동 생성(고객의 SNS 자랑 → 자연 마케팅).
3. **이탈 위험 예측 대시보드:** 출석 빈도 하락·노쇼·메시지 무응답 신호로 위험 고객 조기 경보.
4. **고객 셀프 체크인/문진:** 컨디션·수면·통증 간단 입력 → 리포트·세션에 반영.
5. **결제·횟수권 관리:** 세션 차감, 결제 연동(토스페이먼츠/카카오페이 등), 영수증.
6. **추천(리퍼럴) 프로그램:** 기존 고객이 친구 추천 → 보상. 신규 유입의 가장 강력한 채널.
7. **PWA(설치형 웹앱) + 음성 퀵액션:** 이동 중 홈화면 아이콘 → 녹음 한 번으로 피드백 등록 (요구사항의 "이동 간 순간 처리" 직접 충족).
8. **운동 라이브러리/프로그램 템플릿:** 자주 쓰는 루틴 저장·복제.

> 우선순위: 1·2·3·7 이 "재등록 + 이동중 처리"라는 주목적에 직접 기여 → MVP 직후 1순위 확장.

## 5. 기술 아키텍처 (제안)

### 5.1 스택
- **프론트엔드:** Next.js(React) + TypeScript, **PWA**(모바일 우선·오프라인 녹음 큐), Tailwind.
- **백엔드:** Next.js API Routes 또는 NestJS/Node. **DB:** PostgreSQL(Prisma). 파일(사진/명함/음성): S3 호환 스토리지.
- **인증:** 자체 인증(이메일/OTP) + 카카오·애플 소셜 로그인(선택). 구글 로그인 비채택(요구사항).
- **백그라운드 작업:** 큐/스케줄러(예약 발송, 리마인드, 생일 트리거) — cron + 작업 큐.

### 5.2 핵심 연동
| 영역 | 연동 | 비고 |
|---|---|---|
| 일정 | **Google Calendar API**(트레이너 OAuth) + **iCalendar(.ics) 생성** | 확정 일정은 모두 RFC5545 포맷 표준화. 고객은 계정연동 불필요 |
| 메시지 | 카카오 **알림톡(정보성)** + **브랜드 메시지(마케팅)** via 발송대행 API + SMS/이메일 백업 | 2026 정책: 친구톡 종료, 알림톡 기준 개편 반영 |
| AI 리포트 | LLM API(키는 관리자에서 암호화 저장) | 멀티 프로바이더 추상화, 프롬프트 템플릿 관리 |
| 음성 | 브라우저 녹음 → STT | 실시간/업로드 후 변환 선택 |
| QR/단축링크 | QR 생성 + 단축 URL(스캔 통계) | 예약·등록 링크 추적 |
| OCR(명함) | 이미지 → 연락처 추출 | 선택 기능 |

### 5.3 보안·개인정보 (한국 PIPA 필수)
- 건강 정보 등 **민감정보**: 별도 동의·최소 수집·암호화 저장.
- **AI/발송 API Key**: 평문 저장 금지, 서버 측 암호화(KMS) + 접근 감사.
- 마케팅 메시지: **수신 동의/거부(옵트아웃)** 관리 의무.
- 데이터 보관·파기 정책, 접근 권한 분리, 감사 로그.

## 6. 데이터 모델 개요 (초안)
- `Trainer`(프로필, 영업시간, 예약규칙, 캘린더연동, 발송채널설정)
- `Client`(연락처, 목표, 건강특이사항, 생일/기념일, 동의상태, 상태: active/past/at-risk)
- `Availability` / `Booking`(슬롯, 상태, 캘린더 이벤트 ID, 출결/노쇼)
- `Session` / `SessionPackage`(횟수권, 잔여세션)
- `Report`(고객·날짜·음성원본·STT·AI본문·발송상태·열람기록)
- `MessageJob`(채널, 템플릿, 예약시각, 결과 로그)
- `Trigger`(생일/기념일/잔여세션/이탈위험 규칙)
- `AdminSetting`(API Key(암호화), 모델, 프롬프트, 채널 키)

## 7. 개발 로드맵 (단계별)

### Phase 0 — 기반 (1~2주)
- 프로젝트 셋업, 인증, 데이터 모델, 관리자 골격, API Key 암호화 저장.

### Phase 1 — MVP (재등록 핵심 루프) (3~5주)
1. 고객 등록(QR·셀프링크·직접입력) + 고객 현황 대시보드
2. 일정: 가용규칙 → 예약링크 → 확정 → **구글캘린더/.ics 동기화**
3. 음성 → STT → **AI 리포트 생성·저장·날짜별 열람**
4. 메시지 발송 1종(알림톡 또는 SMS) + 예약 리마인드
> MVP 완료 시점에 "예약 → 세션 → 리포트 → 재등록 안내" 한 바퀴가 돈다.

### Phase 2 — 휴먼터치 & 자동화 (3~4주)
- 생일/기념일/잔여세션/이탈위험 트리거 자동 메시지(검수 모드)
- 카카오 알림톡+브랜드메시지 정식 연동(템플릿 승인), 발송 스케줄 일괄/세부
- 비포/애프터·성과 리포트 공유 카드

### Phase 3 — 전환 최적화 & 확장 (지속)
- 재등록 제안 카드, 이탈예측, 결제/횟수권, 리퍼럴, 통계 고도화.
