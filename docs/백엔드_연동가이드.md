# 백엔드 연동 가이드 (Go-Live)

이 앱은 **"DB 연결이 없으면 데모(목업)로 동작, 연결하면 실제 저장"** 구조입니다.
따라서 **지금 배포 링크는 그대로 동작**하고, 아래 단계를 거치면 **실제 데이터가 저장되는 백엔드**로 전환됩니다.

## 구성 요소 (이미 구현됨)
- **DB 스키마/연결:** `db/schema.ts`, `db/index.ts` (Drizzle ORM + Postgres, 순수 JS)
- **데이터 계층:** `lib/repo.ts` (DB 있으면 Postgres, 없으면 목업 폴백)
- **API:** `app/api/*`
  - `GET/POST /api/clients` — 고객 조회/등록
  - `GET/POST /api/payments`, `POST /api/payments/confirm` — 결제 기록/고객 확인
  - `GET/POST /api/reviews` — 리뷰 조회/등록
  - `POST /api/reports/generate` — **AI 리포트 생성**(키 있으면 Claude, 없으면 템플릿)
  - `POST /api/seed?token=...` — 초기 데이터 주입
- **AI 리포트 화면**(`/reports/new`)은 이미 `POST /api/reports/generate` 를 호출합니다.

---

## 실연동 3단계

### 1) 무료 Postgres 만들기 (Neon 추천)
1. https://neon.tech → 가입(GitHub 가능) → 프로젝트 생성
2. **Connection string**(`postgresql://...sslmode=require`) 복사

> Supabase, Vercel Postgres 등 어떤 Postgres든 OK.

### 2) Vercel 환경변수 등록
Vercel → 프로젝트 → **Settings → Environment Variables** 에 추가:
| 변수 | 값 |
|---|---|
| `DATABASE_URL` | 1)에서 복사한 연결 문자열 |
| `ANTHROPIC_API_KEY` | Claude API 키 (없으면 리포트는 템플릿으로 동작) |
| `SEED_TOKEN` | 아무 비밀 문자열 (초기 데이터 주입 보호용) |

### 3) 테이블 생성 + 초기 데이터
- **테이블 생성:** 로컬에서 `.env` 에 `DATABASE_URL` 넣고
  ```bash
  npm install
  npm run db:push      # 스키마를 DB에 반영
  ```
- **초기 데이터 주입:** 배포 후 한 번 호출
  ```bash
  curl -X POST "https://<your-app>.vercel.app/api/seed?token=<SEED_TOKEN>"
  ```
- Vercel에서 **Redeploy** → 이제 실제 DB로 동작합니다.

## 동작 방식 요약
- `DATABASE_URL` **없음** → 모든 화면이 목업으로 동작 (지금 상태, 데모)
- `DATABASE_URL` **있음** → API가 실제 Postgres에 읽기/쓰기
- `ANTHROPIC_API_KEY` **있음** → 음성 리포트가 실제 Claude로 생성, **없으면 템플릿**으로 자동 폴백 (서비스 중단 없음)

## 메시지/캘린더 연동 (어댑터 구현 완료 — 환경변수만 넣으면 실동작)
코드는 모두 구현돼 있고, **키/웹훅이 없으면 시뮬레이션, 있으면 실제 발송**됩니다.

### 메시지(카카오 알림톡/브랜드 메시지/SMS)
- 어댑터: `lib/kakao.ts`, 엔드포인트: `POST /api/messages/send`
- 환경변수 `MESSAGE_WEBHOOK_URL`(+선택 `MESSAGE_API_KEY`)에 **발송대행사/Make/자체 서버 웹훅**을 연결
- 카카오 알림톡은 **사업자 채널 + 템플릿 승인**이 선행돼야 합니다(회원님 명의).

### 캘린더(구글/네이버)
- 어댑터: `lib/calendar.ts`, 엔드포인트: `POST /api/calendar/event`
- `.ics`(iCalendar)는 **항상 생성**(키 없이도 동작) → 고객/트레이너가 "캘린더에 추가" 가능
- `CALENDAR_WEBHOOK_URL` 연결 시 구글/네이버 캘린더에 자동 등록

### 연결된 화면(쓰기 흐름)
- 고객 등록 → `/api/clients` · 결제 기록 → `/api/payments` · 고객 확인 → `/api/payments/confirm`
- 리뷰 작성 → `/api/reviews` · 리뷰 요청 → `/api/messages/send`
- 음성 리포트 → `/api/reports/generate`(AI) + 저장 `/api/reports` + 발송 `/api/messages/send`
- 예약 승인 → `/api/calendar/event` + `/api/messages/send`

## 회원님만 하실 수 있는 것 (계정/심사)
1. **DB 가입**(Neon 등) → `DATABASE_URL`
2. **Anthropic 키** → `ANTHROPIC_API_KEY` (AI 리포트)
3. **카카오 비즈니스 채널 + 발송대행사 가입**(사업자 심사) → `MESSAGE_WEBHOOK_URL`
4. (선택) **구글/네이버 캘린더 OAuth** → `CALENDAR_WEBHOOK_URL`

> 위 키만 Vercel 환경변수에 넣으면 **코드 수정 없이 전부 실동작**합니다.
> 결제는 "현장 결제 기록 + 고객 공동 확인" 설계라 PG 가입 불필요.
