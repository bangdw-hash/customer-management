## 2. 이 앱들이 공통적으로 **약한/없는** 기능 (우리의 빈틈)
1. **AI 음성 → 리포트 자동 생성** — 거의 없음. 대부분 수기 입력/템플릿.
2. **재등록·재방문 전환 "워크플로우"** — 데이터(잔여횟수 등)는 있어도, *성과 리포트 + 잔여 + 제안*을 묶어 **전환을 설계**하는 흐름은 약함.
3. **휴먼터치 자동화 + 검수 발송** — 생일/기념일/이탈 케어를 *기계적이지 않게* 보내는 장치가 약함.
4. **1인·이동 중심 UX** — 대부분 센터 데스크/PC 또는 회원 검색 앱. "근무 외 시간, 이동 중 1분 처리" 설계가 없음.
5. **성과 스토리텔링** — 비포/애프터 공유 카드(고객의 자랑 → 자연 마케팅)가 약함.
6. **직군 횡단 확장성** — 전부 *한 업종 전용*. 같은 골격인데 업종마다 따로 존재.

## 3. 우리가 이미 가진 차별점 (현재 구현됨)
- 음성→AI 리포트, 재등록 제안 카드, 휴먼터치 자동화 트리거, 이동 중 1분 UX, 접속 시점 실시간 동작, 생동감 있는 비주얼.

## 4. 확장 비전 — **"1:1 프로페셔널 CRM" (헬스 너머)**
핵심 통찰: **"예약 → 세션/시술/레슨 → 성과·케어 → 재방문"** 골격은 수많은 직군이 동일하게 쓴다.

**같은 골격을 쓰는 직군(타깃 확장):**
- 운동·스포츠: 필라테스·요가·골프·테니스·수영·클라이밍·발레/댄스 강사
- 뷰티·바디: 네일·속눈썹·왁싱·피부·타투·헤어·도수/물리치료
- 교육·코칭: 과외·음악/미술 레슨·스피치·커리어 코칭
- 기타: 반려동물 훈련사·심리상담·웨딩/메이크업

**멀티버티컬 전략(한 제품으로 여러 직군):**
- **용어 토큰화:** 고객/회원, 세션/수업/시술/레슨, 잔여세션/잔여횟수, 재등록/재방문 — 업종 선택 시 자동 치환.
- **업종 템플릿:** 문진 항목·리포트 AI 프롬프트·상품(횟수권/회차권)·기념일 트리거를 업종별 프리셋 제공.
- **업종별 온보딩:** 가입 시 "직군 선택" → 화면 문구·템플릿 자동 세팅.

## 5. 추가하면 매력적인 기능 (우선순위 제안)
**[1순위 — 전환·매출 직결]**
- 💳 **결제·횟수권·전자계약** (토스페이먼츠/카카오페이), 노쇼 보증금
- 🎁 **추천(리퍼럴) 프로그램** — 신규 유입의 최강 채널
- 🖼️ **비포/애프터 공유 카드** — 고객 SNS 자랑 → 자연 마케팅
- 🔁 **자동 리텐션 캠페인** — 잔여 임박·이탈 위험 시 자동 제안 시퀀스

**[2순위 — 국내 필수 연동]**
- **네이버 예약 / 카카오싱크 / 카카오 비즈메시지** 연동 (국내 고객 접점)
- 구글/애플 캘린더 양방향

**[3순위 — 1인 사장 운영]**
- 📊 **정산·세무 리포트**(매출/세금계산서), 단골/등급/포인트
- 👥 **팀 모드**(원장-직원, 멀티 트레이너) → 센터까지 확장 → ①센터 CRM 시장도 공략

## 6. UI/UX 재논의 (방향 제안)
현재 구조(하단 5탭 + 음성 FAB)는 1인·모바일 목적에 **적절**합니다. 다만 "생동감 + 정보 위계"를 더 끌어올릴 여지가 있습니다.

**개선 포인트**
1. **Action-first 홈** — "봐야 할 정보"보다 "지금 할 일"(승인·제안·케어)을 **카드 액션**으로 상단 배치.
2. **디자인 시스템 정립** — 그라데이션·네온 글로우(생동감) + 충분한 여백·타이포 위계, **다크모드** 옵션(헬스장 조도).
3. **내비게이션 정리** — "관리"는 설정 성격이 강함 → **프로필/설정 분리** 검토, 핵심 탭은 홈·일정·고객·메시지.
4. **입력 마찰 최소화** — 음성·원탭 우선, 폼 최소화, 스마트 기본값.
5. **상태/접근성** — 빈 상태·로딩 스켈레톤, 색 대비, 터치 타깃 44px, 일관된 모션.
6. **업종 온보딩** — 직군 선택 → 용어/템플릿 자동화로 "내 업종 앱처럼" 느끼게.

**두 가지 실행안 (택1 또는 단계적)**
- **A. 빠른 개선(현 구조 유지):** 위계 재배치 + 여백/타이포 + 스켈레톤 + 다크모드 + 그라데이션/글로우 강화. (빠르고 안전)
- **B. 구조 개편:** 업종 온보딩 + 멀티버티컬 용어 시스템 + 팀 모드까지. (제품 도약, 기간 김)
