# 내 PC에서 프론트엔드 화면 보기 (초보자용 가이드)

코드를 실행해서 `http://localhost:3000` 에서 화면을 보는 방법입니다.
**딱 3단계**예요: ① Node.js 설치 → ② 코드 내려받기 → ③ 실행.

---

## 1단계. Node.js 설치 (최초 1회만)
1. https://nodejs.org 접속
2. **"LTS"** 라고 적힌 버튼 클릭해 설치 파일 다운로드
3. 다운로드한 파일을 실행하고 **계속 "다음(Next)"** 을 눌러 설치 완료
   - (이미 설치돼 있으면 건너뛰세요)

---

## 2단계. 코드 내려받기

### 방법 A — ZIP 다운로드 (가장 쉬움, Git 불필요)
1. 브라우저로 저장소 접속:
   `https://github.com/bangdw-hash/customer-management/tree/claude/blissful-gauss-lzie42`
2. 초록색 **`< > Code`** 버튼 클릭 → **`Download ZIP`**
3. 내려받은 ZIP 파일의 **압축을 풀기** (예: 바탕화면)

### 방법 B — Git 사용 (개발자용)
```bash
git clone https://github.com/bangdw-hash/customer-management.git
cd customer-management
git checkout claude/blissful-gauss-lzie42
```

---

## 3단계. 실행하기

### 압축 푼 폴더에서 "터미널(명령창)" 열기
- **Windows:** 압축 푼 폴더를 연 다음, 위쪽 **주소창에 `cmd` 입력 후 Enter**
  (또는 폴더 안 빈 곳에서 `Shift + 마우스 우클릭` → "PowerShell 창 열기")
- **Mac:** 폴더에서 마우스 우클릭 → **"폴더에서 새로운 터미널 열기"**

### 명령어 2줄 입력 (한 줄씩 Enter)
```bash
npm install
npm run dev
```
- `npm install` : 필요한 부품 설치 (처음 1~2분 걸려요)
- `npm run dev` : 서버 켜기
- `Ready in ...` / `Local: http://localhost:3000` 이 보이면 성공! 🎉

### 화면 열기
1. 브라우저 주소창에 **`http://localhost:3000`** 입력
2. 이 앱은 **휴대폰 화면 기준**으로 만들어졌어요. 더 정확히 보려면:
   - 키보드 **F12** → 좌측 상단 **📱(모바일) 아이콘** 클릭 → iPhone 등 선택

### 꼭 눌러볼 흐름
- **홈 → 가운데 초록 마이크 버튼** → 고객 선택 → 녹음 → 종료 → **AI 리포트 생성** → 발송
- **일정 → "고객 화면 보기"** → 빈 시간 선택 → 예약 확정
- **고객 → 김서연** → 성과(비포/애프터) + 리포트 타임라인
- **관리자** → AI 키 / 모델 / 발송 채널

### 끝낼 때
- 터미널에서 **`Ctrl + C`** 누르면 서버가 꺼집니다.

---

## 자주 묻는 문제
- **`npm` 을(를) 찾을 수 없다고 나와요** → Node.js 설치 후 터미널(명령창)을 **닫았다 다시 열어** 주세요.
- **포트가 사용 중이래요** → 다른 `npm run dev`가 켜져 있을 수 있어요. 그 창에서 `Ctrl + C` 후 다시 실행.
- **화면이 너무 넓게 나와요** → 정상이에요. 위의 F12 → 모바일 보기로 확인하세요.
